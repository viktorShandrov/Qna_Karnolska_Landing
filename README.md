# 🌿 Яна Кърнолска – Психолог | Landing Page & Management Platform

Модерен, елегантен и високопроизводителен уебсайт (Landing Page) с интегрирана система за записване на часове и административен портал за управление на статии, разработен за практиката на психолог **Яна Кърнолска**.

---

## 📖 За проекта

Проектът представлява цялостно дигитално присъствие за психотерапевтична практика. Основният фокус е създаването на топла, предразполагаща и защитена атмосфера за потребителите, съчетана с удобство и автоматизация за терапевта.

Платформата съчетава представяне на услугите, терапевтичния подход, клиентски отзиви, интерактивна форма за записване на час и динамичен блог с полезни статии за психичното здраве.

---

## ✨ Ключови функционалности

- 🌿 **Естетичен и респонсив дизайн**: Специално подбрана цветова палитра в меки, земни и успокояващи тонове, плавни анимации с **Framer Motion** и безупречно потребителско изживяване на всякакви устройства (мобилни телефони, таблети и десктоп).
- 📅 **Интерактивна форма за записване на час (Booking Modal)**:
  - Избор на вид услуга (*Индивидуална терапия*, *Терапия за двойки*, *Онлайн консултации*).
  - Гъвкав избор на желана дата и времеви интервал.
  - Валидация на въведените данни в реално време.
- ⚡ **Директни Telegram известия в реално време**: При всяко успешно изпратено запитване за час, терапевтът получава мигновено структурирано съобщение чрез **Telegram Bot API**.
- 📝 **Динамична блог система и статии**:
  - Арочни и визуално привлекателни карти за четене.
  - Модален прозорец за детайлен преглед на пълния текст, акценти и цитати.
  - Филтриране по категории и изчисляване на време за четене.
- 🔐 **Защитен административен панел (Admin Dashboard)**:
  - Пълен CRUD контрол над статиите (създаване, редактиране, изтриване, предварителен преглед).
  - Вградена галерия с тематични изображения и възможност за персонализирани линкове.
  - Защита с парола и възможност за смяната ѝ директно от интерфейса.
- 🗄️ **Облачна база данни**: Синхронизация и персистентност на данните чрез **Neon Serverless PostgreSQL**.

## 🎯 Предизвикателство и решение

### 🔹 Предизвикателството
Създаване на дигитално пространство за психотерапевт, което да отговаря на следните критерии:
1. Да вдъхва **доверие, спокойствие и конфиденциалност** още от първия визуален контакт, избягвайки студения и шаблонен вид на масовите корпоративни сайтове.
2. Да **автоматизира връзката с клиентите** без нужда от скъпи и тромави външни платформи за резервации.
3. Да осигури **лесна поддръжка и качване на статии** от страна на терапевта без необходимост от технически познания или сложни системи за управление на съдържанието (CMS).

### 💡 Решението
- Разработен е персонализиран **Warm Minimalist / Organic Modern** интерфейс с **React 19**, **Tailwind CSS** и **TypeScript**, акцентиращ върху четимостта и спокойствието.
- Интегриран е директен механизъм за изпращане на заявките към **Telegram**, гарантиращ моментална реакция без забавяне по имейл.
- Създаден е интуитивен, лек и сигурен административен портал с **Vercel Serverless Functions** и **Neon PostgreSQL**, предоставящ пълна независимост и светкавично зареждане без излишни месечни абонаменти за тежки CMS платформи.

## 🚀 Инсталация и локално стартиране

1. **Клонирайте хранилището:**
   ```bash
   git clone https://github.com/viktorShandrov/Qna_Karnolska_Landing.git
   cd Qna_Karnolska_Landing
   ```

2. **Инсталирайте зависимостите:**
   ```bash
   npm install
   ```

3. **Конфигурирайте `.env.local` файл:**
   ```env
   DATABASE_URL=your_neon_postgres_connection_string
   ADMIN_PASSWORD=your_admin_password
   VITE_TELEGRAM_BOT_TOKEN=your_telegram_bot_token
   VITE_TELEGRAM_CHAT_ID=your_telegram_chat_id
   ```

4. **Стартирайте в режим на разработка:**
   ```bash
   npm run dev
   ```

5. **Билд за продукция:**
   ```bash
   npm run build
   ```
